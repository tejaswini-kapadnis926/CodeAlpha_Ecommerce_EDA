# 📊 CodeAlpha E-Commerce EDA Project

## 🚀 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Flipkart E-Commerce Products Dataset using Python.
The main objective of this project is to analyze product ratings, prices, brands, customer sentiment, and product trends to generate meaningful business insights through data visualization and statistical analysis.
---

# 🛠️ Technologies Used
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* TextBlob (NLP)
* Jupyter Notebook
* Power BI
---

# 📂 Dataset Information
Dataset Source:
* Flipkart Products Dataset (Kaggle)

Dataset contains:
* Product Names
* Product Ratings
* Product Prices
* Brands
* Product Descriptions
* Customer Sentiment

---

# 🎯 Key Insights

* Most products have ratings between 3 and 5.
* Positive customer sentiment dominates the dataset.
* Some brands have significantly more product listings.
* Product prices are concentrated in low-to-medium ranges.
* Customer reviews help identify product popularity and satisfaction.
